학습을 시작하는 방법

상단에서 Test와 영역을 고르세요. PDF 페이지 번호를 입력하거나 ← →로 이동하면 오른쪽 답안이 함께 바뀝니다. 책 쪽수도 함께 표시됩니다.

PDF 불러오기로 원본 Cambridge IELTS 21.pdf를 선택하세요. 파일은 서버로 전송되지 않으며 탭을 다시 열면 다시 선택합니다. 기존 오프라인 답안은 JSON으로 내보낸 뒤 이곳에서 가져오세요.

각 페이지의 답안과 시도는 독립적입니다. 같은 문제 번호가 다른 페이지에도 보여도 이후 수정은 해당 페이지에만 저장됩니다. 두 개를 고르는 문항은 각 번호에 하나씩 입력하세요.

Writing은 Task별 긴 답변과 단어 수를 제공합니다. 단어 수는 공백 기준 참고 수치입니다. Listening 음원은 포함하지 않습니다. Reading·Listening은 원본 정답표 기반으로 채점합니다. 대소문자와 앞뒤·연속 공백을 정리하고, 정답표의 허용 표기를 인정합니다. 다른 표현은 정답표와 직접 확인하세요. Writing은 원본 샘플 비교를 제공합니다.

입력 즉시 자동저장됩니다. 같은 브라우저·같은 HTML 경로에서 다시 여세요. 파일 이동, 브라우저 데이터 삭제, 비공개 모드에서는 저장을 유지하지 못할 수 있습니다. JSON 내보내기/가져오기로 답안을 옮기세요. 내보내기는 모든 시도와 메모를 포함합니다. 가져온 답안은 새 시도로 추가되며 기존 시도를 보존합니다. 빈 시도 또는 현재 답안 복사로 다음 풀이를 시작하고, 시도별 비교에서 변화와 메모를 확인하세요.

앱에는 인터넷 요청이나 외부 라이브러리가 없습니다. ZIP은 압축을 풀고 index.html을 여세요. 단독판은 IELTS-21-Standalone.html 하나만 열면 됩니다.
