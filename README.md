# IELTS Study Desk

기기의 Cambridge IELTS 21 원본 PDF를 선택해서 공부하는 앱입니다. PDF와 교재 페이지 이미지는 저장소에 포함하지 않습니다. 선택한 PDF는 서버로 전송되지 않습니다. 원본 파일의 해시를 확인하여 페이지 매핑이 다른 판본을 방지합니다.

답안, 페이지별 시도, 형광펜과 메모는 현재 브라우저에 저장됩니다. 다른 기기로 옮길 때 JSON 내보내기/가져오기를 사용하세요. 기존 오프라인 HTML의 답안도 JSON으로 옮길 수 있습니다. PDF는 탭을 다시 열 때 다시 선택합니다.

GitHub Settings → Pages → Source를 GitHub Actions로 설정합니다. main에 게시하면 배포됩니다. PDF.js 5.6.205를 빌드 시 설치하여 같은 사이트에서 제공합니다.
